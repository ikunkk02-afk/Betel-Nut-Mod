# 5.7.0 进度系统

在原版进度界面中提供 24 个工艺节点和 4 个空岛节点。全部资源继续使用 Fabric 版的 `betel-nut-mod` 命名空间。

## 工艺路线

| 路线 | 节点 | 判定 |
| --- | --- | --- |
| 入门 | 槟榔工艺 | 获得散果、任意果串、槟榔叶、原木或树苗 |
| 种植 | 整串采收 → 等到金黄 → 留作种子 → 种下新一轮 | 成功剪刀采收；成熟采收；获得树苗；真实放置树苗 |
| 循环 | 回到泥土、物尽其用 | 玩家从 8 级堆肥桶取出骨粉；获得木板 |
| 加工 | 营火飘香 → 一叶一果 | 获得熟槟榔、裹叶生槟榔 |
| 口味 | 调味工作室 → 矿物调色盘 → 风味收藏家 | 分别获得三种基础口味、三种矿物口味、十七种变种 |
| 复合 | 合成天下、富甲天下、地底槟榔 | 沿用原 ID、物品条件与奖励，接到矿物加工节点下 |
| 探索 | 河岸来客 → 古城遗物 → 回声留存 | 获得普通贝壳、远古贝壳、回响槟榔 |
| 交易 | 与农民合作 → 拆包时刻 → 三款齐备 | 真正交易买到封签；真正打开混合装；分别获得三款包装 |
| 恢复 | 备好退路 → 缓解有方 → 重新出发 | 获得恢复饮品；实际降低已有依赖/戒断/暴露；用恢复用品将三项清零 |

十七种变种为辛辣、甜味、清凉、夜行、提神、蜂蜜、荧光、幻翼、末影、青金石、石英、岩浆、紫水晶，以及合成天下、富甲天下、地底和回响。分别获得后即可移走物品，部分完成记录会保存。

## 空岛路线

进入经典或一方块空岛 → 实际从堆肥桶取出骨粉 → 水中召雷仪式 / 进入末地。两条末地准备路线平行显示，入末地不要求先完成仪式。仅在已启用的槟榔空岛世界发放新的空岛堆肥与入末地进度。

新工艺堆肥节点适用于普通世界和空岛，要求玩家取出成熟堆肥产物，不追踪输入材料，也不归功于漏斗自动提取。描述明确说明操作条件。

## 兼容与维护

- 所有旧 ID 与 criterion 名保持稳定；错误获取条件已经触发的旧成就仍保留，不撤销历史记录。
- `eat_first_betel_nut`、`get_first_residue`、`addiction_started`、`withdrawal_started`、`eat_hecheng_tianxia` 五个隐藏辅助节点继续供 FTB Quests 等任务包使用。
- 旧版收藏节点的奖励不变；重新载入不会重新奖励已经完成的节点。
- `scripts/generate-advancements.py` 维护新增节点、父子关系及双语文本。修改后运行该脚本并检查差异。
- 可选客户端验证代码位于 `art-rework/advancements-v5.7.0/dev/`，不会打包进发布 JAR。`scripts/prepare-advancements-preview.py` 创建隔离存档并写入使用 5.6.0 原判定名的完成快照。

