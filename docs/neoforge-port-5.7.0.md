# NeoForge 5.7.0 移植记录

源工程：Fabric 5.7.0，提交 `45a37b8`。目标：Minecraft 1.21.1、NeoForge 21.1.259、Java 21。

## 实现

- 所有注册项、模型、纹理、中英文、配方、标签、战利品、世界预设和进度统一到 `betel_nut_mod` 命名空间。
- 在 NeoForge 注册事件内创建和注册对象，避免静态构造时注册表冻结。
- 服务器生命周期、玩家动作、命令、村民交易重载和战利品加载采用 NeoForge 事件。实验交易沿用原版对未覆盖职业的正常交易回退。
- 玩家状态使用原生数据附件，保留原 NBT 字段和死亡复制规则；空岛数据使用 SavedData，每次修改标脏。
- 成瘾同步采用原生 S2C payload；客户端类仅通过客户端入口加载，专用服务器不加载渲染类。
- 24 个树叶网格改为 NeoForge 自定义几何加载器，保留双面、顶点法线、旋转与物品显示变换。
- 自然生成用原生 add_features 群系修改器，实际生成继续执行原配置、根部群系、河岸和世界生成区块边界检查。
- Fabric 资源条件替换为 NeoForge 资源条件；Farmer's Delight 原有厨具配方按 NeoForge 版本验证。
- 增加 25 条 Create 可选配方；机械手剪刀采收沿用原来的服务器方块交互。
- MidnightLib 1.9.2 为内嵌依赖；无 Fabric API、CCA 或加载器桥接依赖。

## 验证范围

原有 116 项 GameTest 完整移植，增加 5 项原生附件保存／死亡复制、世界数据落盘读回、可选 Create 配方、实际机器输入／产出及机械手采收测试。

客户端验证创建普通世界、经典空岛和一方块空岛，逐个退出并重新进入，检查附件数据、玩家方块改动、岛屿生成记录和开局物资防重复。画面覆盖树冠、左右手树叶、第三人称、青黄果串、门／活板门、HUD、进度与两种空岛。客户端直接确认树叶物品模型为 `PalmModel`，包含 746 个烘焙面。

自然生成探针使用原版普通世界和固定种子 20261011，读取实际生成的区块，检查疏林丛林、丛林、竹林和邻近河流的特征注入、树根群系与干燥根部。报告见 `verification/natural-world-report.json`。

日志与机器可读结果保存在 `verification`；截图原图保存在开发运行目录的 `screenshots`。发布包完整性、资源对应和源码包检查由 `scripts/verify-port.py` 完成。

## 使用边界

NeoForge 与 Fabric 的 ID、存档组件格式不同。本次交付是独立 NeoForge 版，没有自动转换旧 Fabric 存档。可选联动已针对 Farmer's Delight 1.3.4 和 Create 6.0.10 验证；其他版本未逐一验证。

工程现维护在原仓库的 `codex/neoforge-1.21.1` 分支，当前版本为 5.7.1；机械动力配方调整见 `docs/create-production-5.7.1.md`。本页保留 5.7.0 的移植记录，最新验证结果见 `verification/report.json`。
