# 原料与骨粉催果 5.8.0

普通贝壳现在可从泥土或沙砾的掉落中获得：每次破坏有 10% 概率额外得到 1 个贝壳，不替换泥土、沙砾或燧石。钓鱼和渔夫交易路线保留。远古贝壳仍只从古城宝箱取得，不会出现在挖掘掉落中。

槟榔树叶普通破坏或自然凋落有 50% 概率掉落 1 片槟榔叶；不掉落生槟榔或果串。剪刀和精准采集仍收集完整树叶。砍伐绿色冠轴时，每块冠轴原木额外掉落 1 棵树苗；树干上的果串失去支撑后掉落对应的完整青果串或黄果串。黄果串加槟榔叶合成树苗的配方继续可用。

对完整槟榔树任意一段竖直树干使用骨粉，一次消耗 1 个，催熟现有青果串并补齐最多 3 串黄果串。也可对青果串直接使用 1 个骨粉立即催熟。树苗长树继续沿用原有规则。

骨粉催果不受群系和光照限制；自然再生与成熟仍检查光照。树根土壤、连续树干、绿色冠轴和树冠必须完整，新果串及其下方必须留空。成熟且满果的树、已成熟果串、旧空果梗、被砍断的树和没有空间的树拒绝施肥，不消耗骨粉。发射器使用相同规则。

机械动力水洗原料的兼容配方在 NeoForge 5.8.0 中提供，详见 NeoForge 项目的同名文档。
