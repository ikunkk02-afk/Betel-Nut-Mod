# 5.6.0 空岛生存改进

经典槟榔空岛和一方块空岛补齐生产链起点。世界预设、岛屿形状、槟榔效果、疾病、普通槟榔与变种加工配方均沿用现有设计。一方块中心不会挖掘刷新。

## 开局物资

两种模式共同提供下列物资。经典模式装入首次生成的箱子；一方块模式首次进入时发到玩家物品栏。

| 用途 | 物资 |
| --- | --- |
| 采收与工具 | 剪刀 ×1、铁锭 ×2 |
| 生长与水石循环 | 骨粉 ×8、冰 ×2、熔岩桶 ×1 |
| 木材、苹果与蜂巢 | 橡树树苗 ×1、蒲公英 ×1 |
| 可可种植 | 丛林树苗 ×4、可可豆 ×1 |
| 主食与糖 | 小麦种子 ×2、甘蔗 ×1、面包 ×8 |
| 泥土循环 | 苔藓块 ×1 |
| 中后期材料 | 紫水晶母岩 ×1 |
| 备用恢复 | 缓解药剂 ×2、金苹果糨糊 ×1 |

经典岛保留原有生槟榔 ×3、烤槟榔 ×1、槟榔树苗 ×1、槟榔渣 ×2、木棍 ×4，并增加泥土 ×4，按原配置提供指南。

一方块保留原有树苗、泥土、烤槟榔的数量配置，另有泥土 ×4、槟榔渣 ×18 和指南。默认共 5 个泥土。18 个渣可压成 2 个渣块，先扩出落脚点。最初的世界仍只生成一个渣块。

这些是有限的开局资源，不能重新登录或死亡重复领取。备用药剂沿用现有每日使用限制和治疗规则。

## 可持续生产

1. 保住泥土、水源和树苗，先用渣块扩建。槟榔树在空岛只需足够光照即可自然生长，骨粉用于加速。
2. 树叶普通破坏获得叶子。剪刀右键采收整串；绿串拆 3 个生果，黄串拆 5 个，或与叶子合成树苗。保留完整根部、树干和树冠，等待再次结果。
3. 两种已启用的空岛预设中，可手持生槟榔、槟榔叶或完整树叶右键堆肥桶。生果增加层数的概率为 65%，叶子为 30%；空桶首层必成功。七层后等待原版成熟延迟，再空手取骨粉。
4. 新增投入物仅支持手动堆肥。原有渣和渣块的堆肥概率、原版可堆肥物、漏斗行为保持原样；普通世界不启用这三种额外投入物。
5. 两块冰放在有底的容器中打碎，建立无限水。用水与熔岩建立刷石机；小麦制作面包，甘蔗用于糖。以普通食物维持饥饿值，生产不用依赖反复吃槟榔。
6. 苔藓在骨粉作用下覆盖石头并生成杜鹃；杜鹃树下生成缠根泥土，继续扩大种植用地。花旁种橡树可尝试生成蜂巢；丛林木用于可可种植。四棵丛林树苗也可种成大型树，改善树苗回收。
7. 紫水晶母岩需就地保护、留出侧面空间，收获长成的晶簇。母岩不能挖走，即使用精准采集也不能回收。
8. 刷怪取得铁与红石，治愈僵尸村民后交易；下界取得石英、金与烈焰棒，逐步加工和成天下。默认水中仪式仍消耗 16 颗末影之眼与 12 个和成天下，给 12 个门框；另外需要 12 颗眼睛激活。

原有虚空群系没有怪物生成列表。本次仅在两种已启用空岛的主世界、虚空群系且原生成列表为空时，使用原版平原的怪物候选，包括僵尸、女巫和末影人。仍需玩家建造刷怪平台，并满足原版距离、亮度、难度和怪物数量限制。共享群系数据、世界预设、普通世界、关闭的空岛模式、其他生物类别及已有的非空生成列表都沿用原规则；旧空岛也能使用这条路线。

九页中英指南覆盖这些步骤。槟榔导致的成瘾、口腔风险、口腔癌二级以上食物限制继续生效。

## 救援与保存

- 首次进入、管理员回岛传送及虚空救援，在已记录出生点周围 16 格范围、上下 16 格内寻找可站立且身体空间无障碍的位置；支持下半台阶，避开流体、火、岩浆块、仙人掌等危险。
- 附近没有安全地面时，默认在出生点附近空处放一个基岩落脚点。不会清除方块或建筑；基岩无法生存采集，重复救援使用同一个落脚点。
- 新增 MidnightLib 配置 `skyblockEmergencyPlatform`，关闭后无安全落点时传送会失败。总开关 `enableBetelSkyblockVoidProtection` 和每种模式的救援开关共同控制自动救援。
- 原有世界坐标、生成标记、reset/force_generate 规则和玩家首次领取标记保持兼容。
- 旧世界缺少 `survivalSuppliesProvided` 时，向首位在主世界存活、未低于救援高度的玩家补发一次共享物资，标记随 CCA 世界组件保存。原箱子和建筑不变；关闭该模式开局物资时不补发。
- 旧一方块中已领取原物资的玩家可触发共享补发；如果首先进入的是从未领取的新玩家，则其完整首次领取同时完成世界升级，避免重复发放。

## 验证

- 标准构建和 Farmer's Delight Refabricated 1.21.1-3.3.6 环境均通过 107 项服务器 GameTest，包括 9 项新增空岛测试。
- 原有 `checkSkyblockPersistence` 保存与防覆盖检查通过。
- 真实客户端确认两个预设自动初始化、物资数量、果串再生与剪刀采收、堆肥交互数据包、受阻出生点和全岛被拆后的救援，以及退出重进后地形、箱子、领取标记的保存。
- 在两个实际虚空存档中建造受控刷怪平台，调用原版自然生成流程，确认实际生成怪物；游戏测试另行核对普通世界、关闭模式及其他生物类别不受影响。
- 用游戏字体测量并截图全部 18 个中英书页，均适配原版 114×128 文字区；修复了英文长页被截断的问题，并抽检最长英文页和中文末地页。
- `python -X utf8 scripts/verify-skyblock-release.py` 核对修改范围、原有资源、源码包、安装包资源和测试代码排除，输出本地 `art-rework/skyblock-v5.6.0/verification.json`。

可选客户端验证：先用 `scripts/prepare-skyblock-preview.py` 准备独立的新测试存档，再运行 `gradlew -PskyblockPreview runSkyblockPreviewClient`。开局验证会改动测试世界，需使用新存档。完成后可运行 `gradlew -PskyblockPreview -PskyblockGuideOnly runSkyblockPreviewClient` 检查中英书页，或加 `-PskyblockMobPreview` 检查实际怪物生成。这些辅助代码不打入安装包。
