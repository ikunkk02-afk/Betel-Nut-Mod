# 5.3.0 槟榔树：叶子、完整果串与育苗

## 采集与用途

| 来源 | 获得物 | 用途 |
| --- | --- | --- |
| 普通破坏／自然凋落槟榔树叶 | 1 片槟榔叶 | 裹叶与变种加工、树苗制作 |
| 剪刀／精准采集收集树叶 | 完整树叶方块 | 建筑，或农夫乐事砧板切成 2 片槟榔叶 |
| 剪刀右键青色果串 | 1 串未成熟槟榔果串 | 工作台拆为 3 个生槟榔，或用农夫乐事刀具砧板加工 |
| 剪刀右键黄色果串 | 1 串成熟槟榔果串 | 拆为 5 个生槟榔，或与槟榔叶制作 1 棵树苗 |

两种果串均整串摘下，原方块立即变为空气，没有留在树上的空果梗。主手、副手剪刀均可，每次仅消耗 1 点耐久。重复交互旧方块状态不会再次掉落。普通破坏果串方块也掉落对应颜色的完整果串，空果梗没有物品掉落。

工作台拆果为无序配方，一串得到对应固定数量的生槟榔，不保留空果串。安装农夫乐事后也可以用刀具在砧板处理，数量相同。所有生槟榔继续使用原来的营火烘烤、裹叶加工路线，不改动普通和变种槟榔配方。

育苗使用“成熟黄色果串 + 槟榔叶 → 1 棵槟榔树苗”。原来的“生槟榔 + 槟榔叶”配方已替换，绿色果串不能直接育苗。树叶和切叶都不再提供散果或树苗。

## 树木重新结果

重新结果由绿色冠鞘下方的树干节点负责。即使所有果串都被摘光，仍会重新长出青色果串，每棵树最多同时保有 3 串。青果在充足光照下成熟为黄色。

条件：

- 节点上方保持两节竖直冠鞘和中央树冠。
- 节点下方连续树干连至适宜泥土或耕地，根部未被砍断。
- 目标位置与果串垂落所需位置为空气，光照至少 9，不覆盖建筑、液体或已有果串。
- 树木位于已加载、接受原版随机刻的区块。结果节点和青果在各自随机刻中以 1/5 概率推进；不是固定时间倒计时，关闭随机刻会暂停。

自然生成时可能暂时没有果实的完整树木也会逐渐结果。砍断的树、没有树冠的树或单独装饰原木不会凭空产果。成熟果串停止自身随机生长刻。

## 兼容与显示

保留 `betel_nut_cluster` 方块 ID 与 `age=0/1/2` 状态，以兼容已有树木。`age=1` 为绿色，`age=2` 为黄色；旧 `age=0` 空果梗在随机刻更新时移除，再由树干生长新果串。

已有 `betel_nut_cluster` 物品 ID 对应成熟黄色果串，新绿色物品 ID 为 `unripe_betel_nut_cluster`。放置和创造模式选取会保留对应成熟度。绿色物品复用树上已有青果模型与 UV，居中和左右手、第三人称变换沿用已修复的果串物品模型；没有重绘贴图或替换树形。

这次不改变自然生成群系、树群分布、树高、树叶姿态、木材碰撞与木质方块，也保留 5.2.0 恢复用品和进食规则。

## 验证

全套测试覆盖整串采收、主副手耐久、防重复掉落、连续多轮采收与重新结果、旧果梗清理、完整树条件、光照、成熟、树叶凋落和工具掉落、果串放置与选取、工作台加工和黄色育苗。

可选联动测试使用实际 Farmer's Delight Refabricated 1.21.1-3.3.6 砧板，验证青果 3、黄果 5、树叶只产 2 片叶子。独立客户端验证真实剪刀使用数据包和掉落、采后空位、加速服务器随机刻中的重新结果及成熟，以及左右手、第三人称、背包与中文提示。
